# Marketing Agents Rules

## Scope

- Keep work inside `marketing-agents/` unless the task explicitly spans another root.
- Treat `data/` and `briefs/` as workflow state and generated compatibility artifacts, not as general scratch space.

## Verification

- Run only the scripts or checks that match the touched workflow.
- Update README or runbooks when queue files, prompts, or automation flows change.

## Handoff

- Call out any required operator review of generated briefs or queue files.
