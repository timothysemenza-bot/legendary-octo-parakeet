# Archive

This folder holds projects and experiments that are worth keeping, but are not part of the active ProposalOps product lane.

## Why this exists

The repo had started mixing:
- the main product,
- client work,
- operational tooling,
- and unrelated experiments.

Keeping archived work here preserves the history without letting it compete with the flagship.

## What belongs here

- old prototypes
- standalone game experiments
- one-off concept mocks
- side explorations that do not currently support ProposalOps
- legacy root-level systems that are no longer part of the active repo story

## What does not belong here

- current ProposalOps product work
- active Boss Key website or marketing automation work
- active client work in `projects/`
- generated deliverables in `outputs/`

## Rule of thumb

If a project is not part of the answer to "What are you building right now?", it should probably live here.
