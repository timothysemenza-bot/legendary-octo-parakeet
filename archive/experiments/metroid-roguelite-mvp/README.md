# Project Nebula (Working Title)

Standalone top-down roguelite inspired by the room-combat/item-synergy structure of The Binding of Isaac, with exploration and ability progression inspired by Metroid-style design.

## What this package contains
- `MVP-DESIGN.md`: mechanics, gameplay loop, scope, and production plan
- `PROJECT-STRUCTURE.md`: proposed Godot 4 project layout
- `data/*.json`: starter data-driven content files

## Core constraints
- Build as a new game from scratch, not an Isaac mod
- Use original art/audio/names/lore
- Treat Isaac and Metroid as reference points for mechanical patterns only

## Recommended engine
- Godot 4.3+ (2D workflow is fast and data-driven setup is straightforward)
