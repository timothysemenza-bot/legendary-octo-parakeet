# Revenue-IQ x Boss Key Proposal Agent MVP

This package implements the MVP and commercialization artifacts for a facilities-focused proposal agent.

## Run

1. Open `workspace/revenue-iq-mvp/index.html` in a browser.
2. Click `Seed Demo Data` for the live walkthrough.
3. Use `Generate Draft Version` to create `proposal_draft_v1` output.
4. Use `Open Weekly Report` for meeting-ready reporting.

## Included Modules

- `RFP Intake`
- `SharePoint Asset Index`
- `Qualification Dashboard`
- `Go / No-Go Decision`
- `Red-Team Draft Workspace`
- `Reviewer Notes`
- `Version History`
- `Audit Trail`
