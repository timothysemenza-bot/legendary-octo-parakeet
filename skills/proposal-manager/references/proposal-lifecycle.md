# Proposal Lifecycle

## Intake Fields

Capture these inputs before drafting the response package:

- customer and opportunity name
- solicitation ID, amendment status, and procurement URL or source file
- due date, submission time, timezone, and submission method
- response type, volumes, page limits, file rules, and required forms
- evaluation criteria and scoring weights if available
- key dates: questions deadline, site visit, bidder conference, oral presentation
- incumbent posture, teammates, subcontractors, and expected competitors
- pricing owner, contracts owner, and executive approvers
- win themes, proof points, past performance, resumes, and certifications
- known risks, assumptions, and missing source artifacts

## Standard Work Products

| Artifact | Purpose |
| --- | --- |
| intake brief | Establish the working facts and open questions. |
| compliance matrix | Map every instruction, requirement, and deliverable to an owner. |
| annotated outline | Turn evaluation criteria into the response structure. |
| page allocation | Reserve space for priority discriminators and required content. |
| proposal calendar | Anchor kickoff, draft deadlines, reviews, production, and submission. |
| kickoff pack | Align authors, reviewers, dependencies, and rules of engagement. |
| data calls | Request pricing, staffing, past performance, resumes, and approvals early. |
| issue log | Track reviewer comments through closure. |
| submission checklist | Validate the final package before upload or delivery. |
| lessons learned log | Preserve improvements for the next pursuit. |

## Stage Flow

1. Intake: register the solicitation, deadlines, and source files.
2. Compliance framing: extract requirements, instructions, and forms into an owner-based structure.
3. Strategy transfer: connect capture context to win themes and discriminators.
4. Content planning: finalize outline, page budgets, assignments, and dependencies.
5. Drafting: manage narrative, graphics, pricing coordination, and version control.
6. Review: run Pink, Red, and Gold gates with clear exit criteria.
7. Submission: verify approvals, files, portal readiness, and contingency plans.
8. Archive: capture artifacts, decisions, and lessons learned.

## Escalate Early

Escalate immediately when any of these conditions appear:

- fewer than 5 business days remain before submission
- pricing assumptions are unresolved
- no approved win themes exist
- mandatory forms or attachments are missing
- executive approvals do not have owners
- the customer portal has not been tested or accessed
