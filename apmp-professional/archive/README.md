This folder holds non-primary APMP working artifacts so the active `deliverables` folder stays clean.

- `deliverables/previews/`: exported slide and CV preview folders from earlier visual passes
- `deliverables/backups/`: point-in-time backups of the live submission deck
- `deliverables/design-pass/`: alternate PPIP versions created for visual experimentation, plus their preview exports

Primary files intended for active use remain in `apmp-professional/deliverables/`.
