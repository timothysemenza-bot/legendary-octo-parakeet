# Style Archetypes

Use one primary and one supporting archetype.

## 1) Trusted Steward
- Best for: nonprofits, faith-led organizations, institutions
- Keywords: trust, dignity, continuity, clarity
- Typography: refined serif headlines + clean sans body
- Visual direction: documentary-style photography, restrained motion, editorial spacing
- UX bias: reduce friction, highlight credibility and process clarity

## 2) Strategic Mentor
- Best for: coaching, advisory, leadership programs
- Keywords: guidance, growth, structure, confidence
- Typography: elegant headlines + precise geometric sans
- Visual direction: candid collaborative scenes, workshop moments, light overlays
- UX bias: roadmap sections, clear progression, strong CTAs

## 3) Community Catalyst
- Best for: member networks, associations, local initiatives
- Keywords: belonging, participation, momentum, contribution
- Typography: approachable sans + personality accent display
- Visual direction: group interaction, real people, high warmth
- UX bias: events and member pathways are primary

## 4) Premium Operator
- Best for: executive audiences, high-accountability teams
- Keywords: precision, excellence, execution, outcomes
- Typography: high-contrast serif + modern sans
- Visual direction: minimal but rich; deliberate whitespace; subtle motion
- UX bias: proof, metrics, and decision-ready information

## Mapping Heuristic

- If values include `integrity`, `tradition`, `ethics`: use `Trusted Steward`.
- If values include `performance`, `coaching`, `leadership`: add `Strategic Mentor`.
- If audience depends on recurring participation and events: add `Community Catalyst`.
- If donor/executive trust is primary: blend in `Premium Operator`.
