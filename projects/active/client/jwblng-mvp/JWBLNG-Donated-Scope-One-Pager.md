# JWBLNG Donated Scope (Constrained MVP)
Date: February 24, 2026

## Purpose
Provide JWBLNG with a focused, no-cost starter implementation that creates immediate clarity and momentum without open-ended scope.

## Donated Deliverables
1. Member Journey Blueprint (1 page)
- Clear path: `discover -> join -> onboard -> first event -> ongoing communications`

2. Website MVP (client-facing)
- Main homepage
- 3 standalone event pages
- Member portal mock view

3. Communication Starter Pack
- Welcome email template
- Event reminder template
- Monthly digest template
- Simple monthly send calendar + owner checklist

4. Basic Launch Setup
- One canonical Join path
- One standard event registration flow
- One donation CTA path
- Basic click/form tracking tags

5. Handoff Session (60-90 min)
- Walkthrough of what is delivered
- Operating guidance for JWBLNG team
- Decision checkpoint for what (if anything) should be a paid phase

## Timeline
- Total duration: up to 3 weeks from kickoff/alignment
- Includes one consolidated revision round

## Explicitly Out of Scope (for donated phase)
- Full Kajabi migration or complete platform rebuild
- Custom backend/CRM development
- Advanced third-party integrations
- Ongoing content/admin management after handoff
- Unlimited revision cycles

## Assumptions
- JWBLNG provides timely content inputs and approvals
- Required platform/logins are available as needed
- Decision-makers are available for one review checkpoint and final handoff

## Success Criteria for This Phase
- A clear and usable member path
- Event pages that can be shared publicly
- Consistent communication templates the team can run
- A concrete basis for deciding whether a later paid phase is needed

## Optional Next Phase (Only If Needed)
If additional implementation is desired after this donated phase, a separate paid scope can be proposed with fixed deliverables, timeline, and cost.
