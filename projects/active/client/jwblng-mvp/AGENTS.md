# JWBLNG MVP Rules

## Scope

- Keep work specific to JWBLNG inside this folder.
- Put generated rollout or handoff bundles in `outputs/`, not inside this project unless the file is source material.

## Verification

- Use the Playwright config in this project for browser workflow changes.
- Keep Kajabi-facing paths and evidence folders accurate.

## Handoff

- Leave clear notes for launch status, rollback impact, and any client-input dependency.
