# Motion Assets for Site Injection

Drop Creative Cloud exports here.

## Required filenames

- `hero-loop.mp4` (homepage hero)
- `portal-loop.mp4` (member portal hero)
- `learning-pulse.json` (homepage program section lottie)
- `network-flow.json` (homepage blueprint section lottie)
- `portal-engagement.json` (dashboard lottie)

## Export guidance

- MP4: H.264, muted, 8-12 seconds, seamless loop.
- Lottie JSON: export from After Effects with Bodymovin plugin.
- Keep animation lightweight (< 800KB each if possible).
