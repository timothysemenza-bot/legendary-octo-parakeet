# POC Output Map

## Objective

Show one representative artifact from each major APMP automation workflow so clients can quickly understand what the system leaves behind.

## Artifact set

| Workflow | Artifact | Purpose |
| --- | --- | --- |
| Capture | `sample-artifacts/01-capture-brief.md` | shows gate logic, discriminators, and next actions |
| Kickoff planning | `sample-artifacts/02-proposal-workplan.md` | shows schedule and milestone discipline |
| Compliance/content | `sample-artifacts/03-compliance-outline-starter.md` | shows requirements traceability and author guidance |
| Review | `sample-artifacts/04-review-issue-log.md` | shows structured review follow-up |
| Knowledge harvest | `sample-artifacts/05-knowledge-harvest.md` | shows reuse and continuous-improvement logic |

## Demo principle

Each artifact should feel like something a proposal lead could use the same day, not a generic AI memo.
