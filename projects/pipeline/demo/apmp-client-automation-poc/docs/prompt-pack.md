# Prompt Pack

Use these prompts from this project root for the proof of concept.

## 1. Orchestrator

Use `apmp-automation-orchestrator` to inspect this project, identify the current APMP lifecycle stage for the sample engagement, run the next justified workflow, and leave a short operator brief with actions, blockers, and the next recommended run.

## 2. Capture cycle

Use `apmp-capture-cycle` to assess the sample opportunity, refresh the capture actions and gate-decision logic, and produce a short packet with owners, dates, risks, discriminators, and a recommendation to advance, defer, or no-bid.

## 3. Kickoff plan

Use `apmp-kickoff-plan` to prepare a kickoff-ready package for the sample engagement, including the proposal schedule, kickoff agenda, role assignments, draft executive-summary direction, and content-planning handoff notes.

## 4. Compliance and content

Use `apmp-compliance-content` to shred the sample requirements, create a requirements baseline, build a compliance matrix starter, and produce an annotated outline with section guidance for writers.

## 5. Review cycle

Use `apmp-review-cycle` to determine review readiness for the sample proposal package, prepare the right review scope, and consolidate comments into a concise issue log with owners and priorities.

## 6. Knowledge harvest

Use `apmp-knowledge-harvest` to convert the latest sample outputs into lessons learned, reusable content objects, and recommendations for standards or repository updates.

## Suggested client-demo order

1. Orchestrator
2. Capture cycle
3. Kickoff plan
4. Compliance and content
5. Review cycle
6. Knowledge harvest
