# Agile Operating Cadence

## Sprint Rhythm

- Sprint length: 1 week
- Planning: Monday, 60 minutes
- Daily standup: 15 minutes
- Backlog refinement: Wednesday, 30 minutes
- Demo + retro: Friday, 60 minutes

## Artifacts

- Sprint goal
- Sprint backlog
- Demo checklist
- Retro action list
- Weekly KPI report

## Definition of Done

- Feature works in live walkthrough
- Tested against 3 RFP samples
- Output documented for non-technical user
- Audit event generated for critical action
