## Working lane

Boss Key's best federal fit is still consulting and support work rather than heavy construction, commodity delivery, staffing-only labor, or defense-heavy technical delivery.

Current best-fit federal lanes:

- management consulting and advisory support
- proposal and bid support
- PMO and program support
- process improvement and operating-model work
- solutions architecture and systems design support
- web, portal, and application support work when the scope is service-oriented rather than product-build-heavy

## Order of operations

1. Complete the SAM registration checklist in `sam-registration-checklist.md`.
2. Advance the active SAM case and use `post-validation-completion-checklist.md` the moment validation clears.
3. Register in SAM.gov for `All Awards`.
4. Complete the SBA supplemental page and Small Business Search profile using `small-business-search-profile-draft.md`.
5. Use `federal-certification-path.md` to decide whether any SBA certification is immediately available.
6. Start live federal search and subcontracting work using `federal-search-playbook.md`.
7. Use `prime-target-outreach-list-2026-03-18.md` for the first wave of prime outreach and supplier registrations.
8. Record non-sensitive registration outputs in `sam-post-submission-record.md`.
9. Use `first-federal-shortlist-2026-03-18.md` as the starting pipeline snapshot.
