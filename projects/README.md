# Projects

This folder holds work that is important but should not compete with the main product roots.

## Lanes

- `active/`: live client work and high-touch active engagements
- `internal/`: internal company or personal work that still matters operationally
- `pipeline/`: near-product, incubating, or pre-product work
- `completed/`: finished project roots that should stay accessible but no longer attract active threads
- `shared/`: shared records and shared source material used across working lanes

## Placement rules

- Put source work here.
- Put generated bundles in `outputs/`.
- Add a local `AGENTS.md` if a project has unique workflow rules.
- Keep client work isolated from product code unless a task explicitly spans both.
