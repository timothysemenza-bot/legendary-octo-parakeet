## Role Access Matrix
- Proposal Operator: 1-10 (except final authorization)
- Proposal Manager: 2-10
- Compliance Lead: 4-9
- Reviewer: 8-9
- Executive Approver: 3,4,8,9,10 (gate actions)

## Required Data Contracts by Screen
- Intake Queue: Opportunity summary, missing inputs, owner, SLA timers
- Bid/No-Bid: score criteria, gate A history, rationale, decision payload
- Compliance Builder: Requirement rows, source locators, coverage status, assigned owners
- Drafting Workspace: SectionDraft, citations, unsupported claim flags
- Review Dashboard: ReviewCycle, ReviewComment, rework packet
- Submission Checklist: required artifacts, final cert state, Gate F decision trail
