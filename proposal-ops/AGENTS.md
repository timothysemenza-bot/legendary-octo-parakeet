# ProposalOps Rules

## Scope

- Keep work focused on product code, tests, migrations, docs, and demos inside `proposal-ops/`.
- Treat demo artifacts and Playwright outputs as generated artifacts unless the task is explicitly about them.

## Verification

- Run targeted Python or Playwright checks for the area you touched.
- Update docs or plans when a workflow, route, or module boundary changes.

## Handoff

- Note any migration, fixture, or environment steps required after the code change.
