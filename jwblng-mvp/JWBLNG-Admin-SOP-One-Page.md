# JWBLNG Admin SOP (One Page)
Owner: JWBLNG Admin Team (Jessica / Marcy)  
Prepared by: Timmy Semenza, Boss Key LLC  
Purpose: Run core JWBLNG operations safely and consistently in Kajabi.

## 1) Approve Contact (Grant Free Community Access)
When to use: A new request is legitimate and should be admitted to free JWBLNG community access.

1. Go to `Contacts`.
2. Open saved filter/segment: `pending-review`.
3. Open the contact record.
4. Confirm basic legitimacy (name, email, any notes/referral context).
5. Add tag: `approved-member`.
6. Confirm automation runs:
- Offer granted: `JWBLNG Community Access`
- Welcome/approval email sent
- (Optional) `pending-review` removed automatically

Result: Contact receives free community-level access only (not Insider access).

## 2) Reject / Hold Contact
When to use: Contact is suspicious, incomplete, or needs follow-up before approval.

1. Go to `Contacts` -> `pending-review`.
2. Open contact record.
3. Do **not** add `approved-member`.
4. Add one status tag:
- `needs-follow-up` (more info required), or
- `declined` (not approved)
5. Optional: send manual follow-up email for clarification.

Result: No offer is granted, and contact remains blocked from gated member areas.

## 3) Publish Event
When to use: A new JWBLNG event needs to go live and be shared.

1. Go to `Events` (or community meetup area in Kajabi).
2. Create event with:
- Title
- Date/time + timezone
- Short description
- Registration/RSVP link
- Zoom/meeting link workflow
3. Assign event visibility correctly:
- Free community event -> Community Access area
- Insider event -> Insider-only area
4. Publish event.
5. Trigger/confirm reminder communications (email + optional WhatsApp process).

Result: Members can discover and RSVP using the intended access level.

## 4) Send Update / Newsletter
When to use: Weekly/monthly update, announcements, or event highlights.

1. Go to `Email Campaigns` / newsletter tool in Kajabi.
2. Start from approved JWBLNG template.
3. Keep one clear objective:
- RSVP to event, or
- Read update, or
- Join program
4. Select correct audience segment:
- `community-access-granted` for free members
- Insider segment for Insider-only communications
5. Send test to internal addresses first.
6. Review links and formatting.
7. Send or schedule.

Result: Consistent, targeted communication without leaking private links publicly.

## Guardrails (Always On)
1. Never grant access by email reply alone. Always use tag workflow in Kajabi.
2. Never place private WhatsApp/member links on public pages.
3. Never grant Insider offer unless explicitly intended.
4. Use tags consistently: `pending-review`, `approved-member`, `needs-follow-up`, `declined`.
5. If unsure, hold the contact and escalate internally before approving.
