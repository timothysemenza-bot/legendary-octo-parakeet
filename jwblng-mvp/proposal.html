Donated Scope Proposal

A focused, no-cost starter phase to give JWBLNG clear momentum, a usable member path, and a practical operating baseline without open-ended implementation risk.

Prepared for Jessica Rabinowitz and Marcy Fried

Phase Snapshot

CostDonated
DurationUp to 3 weeks
RevisionsOne round
GoalClarity + launch readiness

What Is Included

  • Member Journey Blueprint: one-page flow from discover -> join -> onboard -> first event -> ongoing updates.
  • Website MVP Package: main homepage, 3 standalone event pages, and member portal mock view.
  • Communication Starter Pack: welcome email, reminder email, monthly digest template, and send checklist.
  • Basic Launch Setup: canonical join path, event registration pattern, donation CTA, basic click/form tracking.
  • Handoff Session (60-90 min): walkthrough, operating guidance, and phase-complete checkpoint.

Boundaries for This Donated Phase

  • Not included: full Kajabi migration or full platform rebuild.
  • Not included: custom backend/CRM build or advanced integrations.
  • Not included: ongoing administration/content operations after handoff.
  • Constraint: one consolidated revision cycle only.
  • Assumption: timely stakeholder feedback and content inputs.

Success Criteria

  • Clear member path and reduced sign-up confusion.
  • Event pages that can be shared externally with confidence.
  • Repeatable monthly communication cadence the team can run.
  • A concrete basis for deciding whether a paid phase is warranted.

Decision After This Phase

If further implementation is needed, a separate paid scope can be proposed with fixed deliverables, timeline, and pricing.

That second phase would be optional and based on what JWBLNG leadership decides after reviewing donated-phase outcomes.
