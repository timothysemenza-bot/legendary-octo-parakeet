# Boss Key Website Rules

## Scope

- Keep edits focused on site pages, assets, microsites, and trust/content surfaces inside `boss-key-website/`.
- Do not mix client-specific deliverables into this root unless they are intentionally being promoted into a reusable site surface.

## Verification

- Verify changed links, assets, and routes through the local root server when possible.
- Update deployment notes when page ownership or published paths change.

## Handoff

- Mention which pages changed and whether any linked assets or feeds also moved.
