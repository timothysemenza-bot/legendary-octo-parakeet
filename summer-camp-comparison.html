How to read the output

Fit score is a decision aid, not a guarantee

  • Direct age matches score higher than camps where fit is inferred from broad preschool wording.
  • Published tuition beats "contact us" because it makes tradeoffs easier to compare.
  • When you enable long hours, camps ending at 5:30 PM or later move up quickly.
  • Use compare mode for a side-by-side table of schedule, costs, and tradeoffs.

If you change the ages beyond the report's original 3-and-5 scope, rankings still use published age windows where available, but some early-childhood centers remain best-effort approximations.
